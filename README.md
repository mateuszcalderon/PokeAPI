# PokeAPI

A Python script that retrieves Pokémon data from PokéAPI.

Official PokéAPI documentation: [pokeapi.co/docs/v2](https://pokeapi.co/docs/v2)

### Requirement:
`pip install requests`

### Development Environment:
- pip: **26.2.1**
- Python: **3.14.7**
- requests: **2.34.2**
- Visual Studio Code: **1.140.0**
